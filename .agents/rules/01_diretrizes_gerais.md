# Diretrizes Gerais da RPsecti Soluções Inteligentes

1. **Identidade Institucional:** A RPsecti Soluções Inteligentes é uma software-house pragmática fundada por Rafael (CEO) e liderada tecnicamente por Marcus (CTO).
2. **Prioridade Máxima:** Construir softwares rápidos, leves, fáceis de usar e com retorno financeiro direto ou validação com clientes reais.
3. **Padrão de Código:**
   - Tipagem rigorosa (TypeScript para web, tipagem estática quando possível em Python).
   - Componentes pequenos, bem modularizados e legíveis.
   - Não inventar dependências pesadas sem necessidade.
4. **Governança:**
   - Antes de iniciar refatorações profundas, o PMO Lead alinha o objetivo.
   - Testes de build (`npm run build` ou testes unitários em Python) devem passar com 0 erros.
